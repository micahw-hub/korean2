# Korean Lookup (free offline version)

Upload every file in this folder to your GitHub repository (Add file, then Upload files),
replacing the old files. Delete the old shim.js from the repository if it is still there.
GitHub Pages then serves the new version at your usual link. No API key is needed.

This version works offline after the first visit. It gives romanization, pronunciation
with sound changes, a Listen button and history. The "Open the AI version" button opens
the Claude page for meanings, examples, translation and questions.
